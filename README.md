# AI Portfolio Case Studies

Hi, I'm **Salma Mazhar**, a science teacher and STEM educator with a BS in Chemistry, moving into online tutoring and AI Product Management.

This repository contains case studies of AI and automation projects I built hands-on. Each PDF explains the problem, the workflow, the tools used, and what I learned, with my original screenshots.

---

## Projects

### 1. Student Assignment Notification Automation (Zapier)
Google Forms → Google Sheets → Zapier → Gmail. When a student submits an assignment, they get an automatic confirmation email.

📄 [Read the case study](Salma_Mazhar_Case_Study.pdf)

### 2. BizGrow AI Agent (n8n)
Form trigger → AI Agent (OpenAI Chat Model + Memory) → Gmail. An AI agent that reads a form submission and sends a personalised email reply.

📄 [Read the case study](Salma_n8n_AI_Agent_Case_Study.pdf)

### 3. NutriScan AI (Visily Wireframe)
A 5-screen wireframe for a food-scanning nutrition app, designed to help users understand what they eat.

📄 [Read the case study](Salma_NutriScan_AI_Case_Study.pdf)

### 4. Pose Classifier (Google Teachable Machine)
An image-based pose classification model trained with Teachable Machine, with notes on how it works and where it can go wrong.

📄 [Read the case study](Salma_Teachable_Machine_Case_Study.pdf)
